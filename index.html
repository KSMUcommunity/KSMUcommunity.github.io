Чтение общих записей без регистрации

Каждый может добавлять ДЗ и модули. Отмены и переносы пар доступны только редакторам.

ДЗ и модули может публиковать любой студент без регистрации. При первом добавлении Supabase создаёт анонимный ID; он сохраняется только в этом браузере. Автор может править своё, редактор — записи группы. Не публикуйте личные данные. Архив всех групп — в блоке «Архив и файлы записей» ниже. Изменения расписания не являются официальными сообщениями КГМУ.

Управление объявлениями

Новость видна на стартовом экране подходящих групп. Можно выбрать отдельную группу, поток, курс, направление или всех пользователей. Только учётная запись глобального администратора может публиковать, редактировать и удалять объявления. Это сообщения студенческого проекта, не официальный канал КГМУ.

Серверный архив включает ДЗ, модули, изменения занятий и объявления; не включает SQL-схему и учётные записи Auth. Публикуйте локальные записи только после резервной копии.

Архив и файлы записей

Локальные ДЗ, модули и изменения занятий всех групп этого устройства — одним файлом. Серверные записи Supabase в архив не входят; импорт добавляет новые записи и ничего не стирает.

При импорте перед изменениями будет скачана копия прежних локальных записей.

Записи текущей группы можно скачать файлом и отправить в чат — одногруппники загрузят их к себе.

При загрузке файла существующие записи обновляются, новые добавляются.
