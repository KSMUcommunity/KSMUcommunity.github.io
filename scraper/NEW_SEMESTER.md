# Новый семестр — делать ничего не нужно

Сайт сам забирает расписание с kazangmu.ru три раза в день (05:17, 11:17, 17:17 по Москве)
и сам замечает, что начался новый семестр.

## Как это работает

1. В шапке каждого Excel-файла КГМУ написано, к какому семестру он относится:
   «РАСПИСАНИЕ ЗАНЯТИЙ на **весенний семестр 2026/2027** уч.г.».
2. Когда КГМУ выкладывает файлы нового семестра (и их не меньше 70% от всех файлов на странице),
   автообновление переключает сайт:
   - **1-я неделя** — понедельник той недели, где в файлах циклов старших курсов стоит самая ранняя
     дата (осенью 2026 это 1 сентября → неделя с 31 августа). Если файлов циклов нет — по правилу:
     осень с недели 1 сентября, весна с недели 9 февраля;
   - **число недель** — последняя неделя, в которой есть занятия (от 18 до 26);
   - **праздники** — нерабочие дни РФ внутри семестра.
3. Все группы пересобираются: группы без занятий в новом семестре убираются, новые добавляются.
4. Настройка сохраняется в `scraper/semester.json`, а в отчёте запуска (Actions → запуск → Summary)
   появляется строка «Новый семестр: …, 1-я неделя с …».

**Защита от ошибок.** Если новых файлов меньше 70% или у трети групп и больше не нашлось занятий,
сайт оставляет прошлое расписание и пробует снова при следующем запуске. Назад, на более ранний
семестр, сайт не переключается никогда.

## Если автоматика ошиблась (ручная замена)

Например, КГМУ сдвинул начало семестра, а дат циклов в файлах нет.

1. Репозиторий → вкладка **Actions** → слева **«Расписание КГМУ»** → **Run workflow**.
2. Указать **понедельник 1-й недели** (например `2027-02-08`), **название** (`Весна 2026/27`)
   и **число недель** (`18`). Нажать **Run workflow** — через 2–3 минуты сайт обновится.

Из консоли то же самое:

```bash
pip install -r requirements.txt
python scraper/new_semester.py --title "Весна 2026/27" --week1 2027-02-08 --weeks 18
python scraper/update_friend.py
git add scraper/semester.json schedule.json schedule-data.js && git commit -m "Весенний семестр" && git push
```

## Что ещё стоит знать

- ДЗ и модули прошлого семестра остаются в базе и видны на своих датах — ничего удалять не нужно.
- Роли старост не зависят от семестра. Если номер группы сменился (новый курс), старосту
  нужно назначить заново в боте: `/admin` → «Назначить старосту».
