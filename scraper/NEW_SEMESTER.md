# Как загрузить расписание нового семестра

Сайт сам забирает расписание с kazangmu.ru три раза в день (05:17, 11:17, 17:17 по Москве).
Внутри одного семестра ничего делать не нужно: изменения в файлах КГМУ появятся на сайте сами.

Когда начинается новый семестр (весенний или осенний), меняются даты: с какого понедельника
считать 1-ю неделю и сколько недель в семестре. Это одна настройка — `scraper/semester.json`.

## Способ 1. Через GitHub (2 минуты, без программирования)

1. Дождаться, когда КГМУ опубликует файлы нового семестра на странице
   https://kazangmu.ru/obuchenie/studentam/raspisanie-zanyatij
2. Открыть репозиторий → вкладка **Actions** → слева **«Расписание КГМУ»** → кнопка **Run workflow**.
3. Заполнить:
   - **Понедельник 1-й недели** — например `2027-02-08` (обязательно понедельник);
   - **Название семестра** — например `Весна 2026/27`;
   - **Число учебных недель** — обычно `18`.

   Или поставить галочку **«Определить семестр по файлам КГМУ»** — название и 1-я неделя
   возьмутся из шапки Excel-файлов («весенний семестр 2026/2027»).
4. Нажать **Run workflow**. Через 2–3 минуты сайт покажет новый семестр.

Что происходит: записывается `scraper/semester.json`, все группы пересобираются с нуля.
Группы, у которых в новом семестре нет занятий, убираются; новые группы добавляются сами.

**Защита от ошибок.** Если у трети групп и больше занятий не найдено (обычно это значит, что
КГМУ ещё не выложил новые файлы), сайт оставляет прошлое расписание. Новая настройка семестра
при этом сохраняется, и автообновление само попробует снова при следующем запуске.

## Способ 2. Из командной строки

```bash
pip install -r requirements.txt
python scraper/new_semester.py --title "Весна 2026/27" --week1 2027-02-08 --weeks 18
python scraper/update_friend.py
git add scraper/semester.json schedule.json schedule-data.js && git commit -m "Весенний семестр" && git push
```

## Праздники

Нерабочие праздничные дни (по ним не ставятся цикловые занятия) лежат в `semester.json` → `holidays`.
`new_semester.py` заполняет их сам; если вуз объявит дополнительные выходные, допишите даты вручную.

## Что ещё проверить после смены семестра

- ДЗ и модули прошлого семестра остаются в базе и видны на своих датах — ничего удалять не нужно.
- Роли старост не зависят от семестра. Если номера групп сменились (новый курс), старост
  нужно назначить заново в боте: `/admin` → «Назначить старосту».
